# 《版次》STATES OF THE PLATE

一位创意前端的自我介绍 · 铜版画隐喻的迭代叙事交互装置

> 我不相信一次做对，我相信一遍遍地逼近。

**在线作品：https://000205as.github.io/states-of-the-plate/**

## 这是什么

我用「铜版画」的方式做前端：起稿、落刀、腐蚀、试印，不满意就回到版上再刻——每一版叫一个「状态」（State）。这个页面就是这种工作方式本身：

- **向下滚动 = 推进版次**：版面从混沌的浮尘，逐渐逼近一幅「山月图」
- **在纸面空白处单击 = 落刀**：留下你自己的刀痕（冲击波 + 弹簧物理 + 永久刀痕）
- **第三章 = 洗版**：墨潮自下而上洗过全版；往前滚墨色加深，往回滚可撤销
- **终章**：成品 + 朱砂印「手泽」落下，题跋写清你落了几刀
- 落刀 8 刀以上，版上浮现隐藏的飞鸟暗记
- 「重刻此版」会用新种子生成一幅完全不同的山月

## 本地运行

```bash
npm ci        # 安装依赖
npm run dev   # 开发预览
npm run build # 构建（tsc 严格检查 + vite + 单文件产物）
```

## 技术

React 19 · Vite 7 · TypeScript，**零运行时依赖**——连动画引擎都是手写的：

- 铜版画由 Canvas 2D 程序化生成（约 4000 根排线，每根线有自己的目标位置与噪声漂移，滚动即「收敛」、点击即「冲击」）
- 纸张 / 铁墨 / 朱砂三色纪律，全站无一行硬编码颜色
- 键盘操作（K 落刀）、焦点样式、`prefers-reduced-motion` 全降级、移动端触觉反馈
- 相机编舞：全貌（幽灵）→ 局部（成形）→ 全貌（成品），首尾同构图呼应

## 部署
